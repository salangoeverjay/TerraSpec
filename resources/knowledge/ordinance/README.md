# Official ordinance texts for the TerraSpec AI assistant

Put the official text of Panabo City ordinances here as plain-text or Markdown files (`.md` or `.txt`), for example:

- `zoning-ordinance.md`: the Panabo City Zoning Ordinance (allowed uses per zone, setbacks, building heights, procedures)
- `hazard-ordinance.md`: any city ordinance on disaster risk reduction, flood or no-build zones

Guidelines:
- Keep the section numbers and headings exactly as in the ordinance, using Markdown headings (`## Section 12. General Commercial Zone`). The assistant cites these headings.
- Start each file with a first line naming the ordinance, e.g. `# Ordinance No. 2021-001: Zoning Ordinance of Panabo City`.
- Do not paste anything that is not official text.

Every `.md` / `.txt` file in this folder except this README is loaded automatically as official ordinance text. Until a file is added, the assistant tells users that allowed-use rules are provisional.
